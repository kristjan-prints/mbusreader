# MBusReader HOWTO

This file contains operational commands and examples for setting up, running, configuring, and maintaining MBusReader.

For the project overview, see [README.md](README.md).

## Install dependencies

From the project root:

```bash
python -m pip install -r requirements.txt
```

Production update:

```bash
cd ~/git/mbusreader
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Update `requirements.txt` after changing the virtual environment:

```bash
python -m pip freeze > requirements.txt
```

## Configure environment

`MBR_API_TOKEN` is required.

Generate a token:

```bash
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

Example environment file:

```bash
MBR_API_TOKEN=PASTE_TOKEN_HERE
MBR_SERIAL_DEV=/dev/ttyAMA4
MBR_BAUD_RATE=9600
MBR_DATABASE_URL=sqlite:////var/lib/mbusreader/mbr.sqlite3
M2M_CLIENT_CERT=/etc/mbusreader/tls/mbusreader.crt
M2M_CLIENT_KEY=/etc/mbusreader/tls/mbusreader.key
SYNC_DELAY_SECONDS=10
```

Load a local environment file:

```bash
cp ./config/mbusreader.env.example ./config/mbusreader.env
set -a
source ./config/mbusreader.env
set +a
```

Create production config directory:

```bash
sudo install -d -m 0750 -o root -g kasutaja /etc/mbusreader
```

Create production environment file:

```bash
sudo nano /etc/mbusreader/mbusreader.env
```

Example production file:

```bash
MBR_API_TOKEN=PASTE_PROD_TOKEN_HERE
MBR_SERIAL_DEV=/dev/ttyAMA4
MBR_BAUD_RATE=9600
MBR_DATABASE_URL=sqlite:////var/lib/mbusreader/mbr.sqlite3
M2M_CLIENT_CERT=/etc/mbusreader/tls/mbusreader.crt
M2M_CLIENT_KEY=/etc/mbusreader/tls/mbusreader.key
SYNC_DELAY_SECONDS=10
```

Protect the file:

```bash
sudo chown root:kasutaja /etc/mbusreader/mbusreader.env
sudo chmod 640 /etc/mbusreader/mbusreader.env
```

## Run the server manually

### Create local development TLS files

From the project root:

```bash
openssl req -x509 -newkey rsa:2048 -nodes \
  -keyout ./local-dev.key \
  -out ./local-dev.crt \
  -days 30 \
  -subj "/CN=localhost" \
  -addext "subjectAltName=DNS:localhost,IP:127.0.0.1"
```

### Running from active venv at IntelliJ terminal

From the project root:

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8443 \
  --ssl-keyfile ./local-dev.key \
  --ssl-certfile ./local-dev.crt
```

### Running from any terminal without active venv

From the project root:

```bash
python -m uvicorn app.main:app --host 0.0.0.0 --port 8443 \
  --ssl-keyfile ./local-dev.key \
  --ssl-certfile ./local-dev.crt
```

### Running from mbusreader-host terminal

Activate the venv:

```bash
cd ~/git/mbusreader
source .venv/bin/activate
```

Load development env variables:

```bash
cp ./config/mbusreader.env.example ./config/mbusreader.env
set -a
source ./config/mbusreader.env
set +a
```

Start app for development and testing:

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8443 \
  --ssl-certfile /etc/mbusreader/tls/mbusreader.crt \
  --ssl-keyfile /etc/mbusreader/tls/mbusreader.key
```

## Database

SQLite database is located at:

```text
/var/lib/mbusreader/mbr.sqlite3
```

The environment file should declare the database location:

```bash
MBR_DATABASE_URL=sqlite:////var/lib/mbusreader/mbr.sqlite3
```

### Fresh install

Create database directory:

```bash
sudo install -d -o kasutaja -g kasutaja -m 0750 /var/lib/mbusreader
```

The database itself is autogenerated when it is missing.

Open SQLite:

```bash
cd /var/lib/mbusreader
sqlite3 mbr.sqlite3
```

Useful SQLite commands:

```sql
.tables
.schema properties
.schema meter_data
.quit
```

## Properties table

Runtime configuration is stored in the SQLite `properties` table.

Active rows have:

```sql
valid_till IS NULL
```

When replacing a property, soft-delete the old row by setting `valid_till`.

### DEVICE_ID

Example for `mbusreader-host`:

```sql
INSERT INTO properties (key, value, valid_from, valid_till)
VALUES (
    'DEVICE_ID',
    json_object(
        'name', 'mbusreader-host',
        'id', 1001
    ),
    unixepoch(),
    NULL
);
```

### MBUS_SLAVE

Example:

```sql
INSERT INTO properties (key, value, valid_from, valid_till)
VALUES (
    'MBUS_SLAVE',
    json_object(
        'name', 'Main meter',
        'id', 210
    ),
    unixepoch(),
    NULL
);
```

Replace `210` with the actual M-Bus primary address.

### Switching the UPLOAD_SERVER

Enter the SQLite DB:

```bash
cd /var/lib/mbusreader
sqlite3 mbr.sqlite3
```

Soft-delete existing active `UPLOAD_SERVER` value:

```sql
UPDATE properties
SET valid_till = unixepoch()
WHERE key = 'UPLOAD_SERVER'
  AND valid_till IS NULL;
```

Insert new `UPLOAD_SERVER` value:

```sql
INSERT INTO properties (key, value, valid_from, valid_till)
VALUES (
    'UPLOAD_SERVER',
    json_object(
        'baseUrl', 'https://rpp.example.com',
        'verify', json('true')
    ),
    unixepoch(),
    NULL
);
```

Exit SQLite:

```sql
.quit
```

Restart the service if the running process does not reload DB-edited properties automatically:

```bash
sudo systemctl restart mbusreader.service
```

## API examples

The full API reference is available in generated FastAPI docs:

```text
https://localhost:8443/docs
```

### Health check

```http
GET /health
```

### Fetch meter data

```http
POST /mbus/meter_data
Content-Type: application/json
Authorization: Bearer <MBR_API_TOKEN>

{
  "slave_address": 210,
  "start_after_timestamp": 1774744200,
  "end_timestamp": 1774749600,
  "limit": 20000
}
```

### Replace meter data in a time window

Use `dry_run: true` to preview the change.

Use `dry_run: false` to apply it.

```http
POST /mbus/meter_data/update
Content-Type: application/json
Authorization: Bearer <MBR_API_TOKEN>

{
  "slave_address": 210,
  "start_timestamp": 1774746000,
  "end_timestamp": 1774749600,
  "dry_run": true,
  "rows": [
    {
      "timestamp": 1774746000,
      "meter_reading": 12345.67
    },
    {
      "timestamp": 1774746900,
      "meter_reading": 12346.12
    }
  ]
}
```

Timestamps for insert/update operations must be 15-minute aligned.

## Upload sync

If an active `UPLOAD_SERVER` property exists, MBusReader schedules an upload sync after meter reading.

The upload server config is stored in SQLite:

```json
{
  "baseUrl": "https://rpp.example.com",
  "verify": true
}
```

`verify: true` means Python `requests` verifies the RPP server certificate using the normal trusted CA bundle.

Client certificate and key are configured through environment variables:

```bash
M2M_CLIENT_CERT=/etc/mbusreader/tls/mbusreader.crt
M2M_CLIENT_KEY=/etc/mbusreader/tls/mbusreader.key
```

Upload sync talks to RPP M2M endpoints under:

```text
https://rpp.example.com/api/m2m/...
```

## TLS certificate setup

The MBusReader certificate is used as:

- HTTPS server certificate for the local FastAPI server.
- Client certificate for RPP mTLS upload sync.

### Create CA on a safe machine

```bash
openssl ecparam -name prime256v1 -genkey -noout -out mbusreader-ca.key

openssl req -x509 -new -sha256 \
  -key mbusreader-ca.key \
  -days 3650 \
  -out mbusreader-ca.crt \
  -subj "/CN=mbusreader-ca" \
  -addext "basicConstraints=critical,CA:TRUE,pathlen:0" \
  -addext "keyUsage=critical,keyCertSign,cRLSign" \
  -addext "subjectKeyIdentifier=hash"
```

### Generate private key on the Pi

```bash
openssl ecparam -name prime256v1 -genkey -noout -out mbusreader.key
```

### Create CSR on the Pi

```bash
openssl req -new \
  -key mbusreader.key \
  -out mbusreader.csr \
  -subj "/CN=mbusreader-host" \
  -addext "subjectAltName=DNS:mbusreader-host,DNS:mbusreader-host.example.com,IP:192.0.2.10"
```

### Create leaf extension file on the CA machine

Create file:

```bash
nano mbusreader-leaf.ext
```

Content:

```text
basicConstraints=critical,CA:FALSE
keyUsage=critical,digitalSignature,keyEncipherment,keyAgreement
extendedKeyUsage=serverAuth,clientAuth
subjectKeyIdentifier=hash
authorityKeyIdentifier=keyid,issuer
```

### Sign CSR on the CA machine

```bash
openssl x509 -req \
  -in mbusreader.csr \
  -CA mbusreader-ca.crt \
  -CAkey mbusreader-ca.key \
  -CAcreateserial \
  -out mbusreader.crt \
  -days 3650 \
  -sha256 \
  -extfile mbusreader-leaf.ext \
  -copy_extensions copy
```

### Install certificates on the Pi

Create TLS directory:

```bash
sudo install -d -m 0750 -o root -g kasutaja /etc/mbusreader/tls
```

Copy files:

```bash
sudo cp mbusreader.crt /etc/mbusreader/tls/mbusreader.crt
sudo cp mbusreader.key /etc/mbusreader/tls/mbusreader.key
sudo cp mbusreader-ca.crt /etc/mbusreader/tls/mbusreader-ca.crt
```

Set ownership and permissions:

```bash
sudo chown root:root /etc/mbusreader/tls/mbusreader.crt
sudo chmod 644 /etc/mbusreader/tls/mbusreader.crt

sudo chown root:kasutaja /etc/mbusreader/tls/mbusreader.key
sudo chmod 640 /etc/mbusreader/tls/mbusreader.key

sudo chown root:root /etc/mbusreader/tls/mbusreader-ca.crt
sudo chmod 644 /etc/mbusreader/tls/mbusreader-ca.crt
```

## systemd setup

Example service file location in repository:

```text
config/mbusreader.service
```

Install service:

```bash
sudo cp config/mbusreader.service /etc/systemd/system/mbusreader.service
sudo systemctl daemon-reload
sudo systemctl enable --now mbusreader.service
```

Example service file:

```ini
[Unit]
Description=MBus Reader
After=network-online.target
Wants=network-online.target
StartLimitIntervalSec=60
StartLimitBurst=10

[Service]
Type=simple
User=kasutaja
Group=kasutaja

WorkingDirectory=/home/kasutaja/git/mbusreader
EnvironmentFile=/etc/mbusreader/mbusreader.env

Environment=PYTHONUNBUFFERED=1

ExecStart=/home/kasutaja/git/mbusreader/.venv/bin/python -m uvicorn app.main:app \
  --host 0.0.0.0 --port 8443 \
  --ssl-certfile /etc/mbusreader/tls/mbusreader.crt \
  --ssl-keyfile /etc/mbusreader/tls/mbusreader.key \
  --proxy-headers

Restart=on-failure
RestartSec=2

[Install]
WantedBy=multi-user.target
```

## Scheduler

The scheduler should use UTC.

The meter reading job runs every 15 minutes:

```text
00, 15, 30, 45
```

Using UTC avoids DST-related missing readings.

## Troubleshooting

### Check service logs

```bash
journalctl -u mbusreader.service -n 200 --no-pager
```

### Check health endpoint

```bash
curl -k https://localhost:8443/health
```

### Check SQLite data

```bash
cd /var/lib/mbusreader
sqlite3 mbr.sqlite3
```

Useful SQLite commands:

```sql
.tables
.schema properties
SELECT * FROM properties ORDER BY id DESC;
SELECT * FROM meter_data ORDER BY timestamp DESC LIMIT 20;
.quit
```

### Check active UPLOAD_SERVER

```sql
SELECT *
FROM properties
WHERE key = 'UPLOAD_SERVER'
  AND valid_till IS NULL;
```

### Check RPP server certificate from the Pi

```bash
openssl s_client -connect rpp.example.com:443 -servername rpp.example.com -verify_return_error -showcerts </dev/null
```

Expected:

```text
Verify return code: 0 (ok)
```

### Test RPP HTTPS from Python

```bash
cd ~/git/mbusreader

.venv/bin/python - <<'PY'
import requests
r = requests.get("https://rpp.example.com/api/session", timeout=10)
print(r.status_code)
print(r.text[:200])
PY
```

Expected: no certificate verification error.

### Test RPP M2M endpoint with client certificate

```bash
curl -v \
  --cert /etc/mbusreader/tls/mbusreader.crt \
  --key /etc/mbusreader/tls/mbusreader.key \
  -H "Content-Type: application/json" \
  -d '{"device_id":1001,"meter_addresses":[]}' \

```
